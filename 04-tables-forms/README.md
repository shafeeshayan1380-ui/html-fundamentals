Explanation

I used method="get" in my HTML form.

When I submitted the form, the browser added the entered values to the URL as query parameters.

The ? separates the URL path from the query string.

The & separates the different parameters.

The name attributes define the parameter names, such as company, position, and status.

The address 127.0.0.1:3000 refers to my local development server.

Conclusion: The GET method sends form data through URL parameters. However, submitting this form does not automatically store the application or add a new row to the HTML table.
