
## Exercise 03 - Semantic HTML

### Why use semantic elements instead of div?

1. **nav instead of div**

   I used the `nav` element because it contains the main
   navigation links of my CV. Unlike a `div`, it has
   semantic meaning and helps assistive technologies
   identify the navigation area.

2. **main instead of div**

   I used the `main` element because it contains the
   primary content of my CV. A `div` is only a generic
   container, while `main` identifies the most important
   content of the page.

3. **section instead of div**

   I used `section` to group related content such as
   Education, Skills, and Projects. Each section has
   its own heading. Unlike `div`, `section` represents
   a meaningful part of the document.
